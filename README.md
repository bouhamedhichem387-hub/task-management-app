# Task Management App

A full-stack productivity application for organizing personal work. The planned experience includes a task dashboard, secure account access, task priorities and statuses, due dates, and useful search and filtering.

## Planned features

- Account registration and login with hashed passwords.
- Personal dashboard with task statistics and progress indicators.
- Create, edit, and delete tasks with priority, status, and due date.
- Search, filtering, and sorting.
- Protected routes and user-scoped task access.
- Backend validation, clear loading/error/empty states, and tests.
- Complete API, setup, environment, and screenshot documentation.

## Technology stack

- Frontend: React, TypeScript, Vite
- Backend: Node.js, Express.js, TypeScript
- Database: MongoDB with Mongoose

## Local development

Installation commands, environment configuration, API routes, and test instructions will be documented as implementation is added. No hosted service is configured.
